# P56：仅展开原生 consumer 七叶外循环

测量前设计，2026-10-16。P55性能拒绝并恢复P51后，依据LITERATURE_UPDATE_P55.md
的自身profile、原始来源和历史复核，研究更窄的consumer编译调度控制。此前P25/P26
改变准备核unroll，P28改变INT8双片段，P46改变高部复用，P52–P54改变瓦片/并发；
没有发现对P51原生consumer七叶外循环的单独完全展开对照。

## 唯一改动与不变量

从冻结P51复制四文件到独立p56目录。只将consume中紧邻`step<7`外循环的
`#pragma unroll 1`改为`#pragma unroll 7`。保留内部K循环unroll1，producer逐字不变。
请求编译器按固定叶顺序0,1,5,6,4,2,3特化plane/低部条件与FP32重组分支；是否成功
必须检查实际编译产物。该pragma不保证编译器展开或提速。

所有原始FP16/BF16输入、精确1024inside、p11/p8低部缩放、原生11平面/两描述符、
完整K512七主乘积和八交叉项及FP32显式RN依赖图不变。每叶d/r寄存器初始化、
compiler operand fences、硬件warpgroup_arrive、四次K128 issue/commit、k>0 wait1
后释放前一槽、最终wait0后读取/释放末槽均逐字保持。四个49152B槽、Shared196736B、
消费grid16×8/256线程、准备384×256/65536B、workspace11804032B不变。
源指令480MMA/CTA、88TMA/CTA、28供数批次和全网格138412032B名义载荷不变。
输出坐标与四象限存储及叶重组顺序不变，不削减任何原始门槛。

## 风险和验收顺序

展开可能增加代码体积、寄存器生存期与指令缓存压力，不能根据分支减少预判提速。
先冻结CPU事件/坐标/依赖等价检查和原始源身份，再生成隔离候选；工作P51暂不改。
独立全网格TMA探针使用新种子128171+491trial+269dtype，六配置/28批次/四槽复用，
同时验证11平面高低部、shared/workspace/output guards及输出坐标双射。producer
与候选逐空白相同。通用读取不是MMA等待顺序证书。编译并查询候选实际资源和
合作式容量，禁止将P51/P55检查数当作P56自身新样本。

这些检查通过后才执行真实候选MMA，运行原始78项门槛/精确inside和完整计时。
独立P51/P56普通及Graph ABBA均计入准备和描述符/计算，保存全部计时臂。
若有收益则运行自身新输入双流/独立workspace、普通/Graph交错/guards及限定范围
三工具；若退步则保留证据、逐字恢复P51并新进程78复核。run不分配/host同步/缓存。
候选自身NCU只做诊断，所有profiler进程计时排除，不建立物理下界。
生产solution/library/Auto和正式iter计数不变；这是研究候选，目标仍未完成。
